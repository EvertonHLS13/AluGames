# AluGames

Aplicacao de console em **Kotlin** que consome uma API de jogos.
Projeto do curso Kotlin: desenvolvendo sua primeira aplicacao (Alura).

## Tecnologias
- Kotlin
- Maven
- Gson
- IntelliJ IDEA

## Funcionalidades
- Consumo de API externa para buscar jogos por ID
- Classes e data classes (Jogo, Gamer, InfoJogo)
- Tratamento de erros com runCatching
- Cadastro de gamer com validacao e encapsulamento
- Lista de jogos buscados
- Extension functions

## Como executar
1. Clone o repositorio
2. Abra no IntelliJ IDEA
3. Execute Main.kt
